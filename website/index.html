OpenCode Bridge

Works with the models and apps you already use

What it unlocks

Three things your apps couldn’t do before.

Free tier

Free OpenCode models, for real.

Big Pickle, DeepSeek V4.1 Flash Free, GLM-5.3 Flash Free, Nemotron — they only run inside OpenCode, so Bridge runs them in a private OpenCode agent. No key, no tricks.

Claude Desktop

Claude names. Your models.

Claude still shows Sonnet 5, Opus 5, Haiku 4.5, Fable 5 and Sonnet 4.6. You choose what answers each one — with its own effort, from Low to Max.

Codex

Codex, on any model.

One click opens codex --profile opencode-bridge, or switches the Codex app to your model. Disconnect restores your config line-for-line.

How it works

Three steps. Thirty seconds.

  1. 01

    Pick a model

    Every model from OpenCode, Ollama and LM Studio — free, local and agent models clearly badged. New downloads appear on their own.

  2. 02

    Map & pin effort

    Point each Claude model name at any backend and pin Low → Max. Requests snap to levels the model really supports.

  3. 03

    Launch

    Open Claude or Codex on your model. Restore puts everything back exactly — journaled before a single byte changes.

Built carefully

Powerful, and politely reversible.

Effort

Low → Max, per model

Pin an effort for each Claude model name or for Codex. Unsupported levels map to the nearest real one — never silently dropped.

Local

Ollama & LM Studio

Native Anthropic endpoints. LM Studio’s server starts and loads your model on launch. Nothing downloads by browsing.

Agent

OpenCode does the work

Agent models run OpenCode’s own tools under your policy — read-only by default, edit & run, or full access.

Security

Loopback only

127.0.0.1, Host checks, a random 256-bit token, and a password-protected OpenCode server. Keys stay in OpenCode.

Recovery

Journaled, exact undo

Claude and Codex edits are journaled before any write. Restore detects outside edits and refuses to clobber them.

CLI

Headless when you want

init, launch, status, restore — everything the app does, scriptable.
